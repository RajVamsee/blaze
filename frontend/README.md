# Blaze — Frontend

Angular 18 frontend for the Blaze collaborative workspace.

## Run locally

```bash
npm install
npm start
# Opens at http://localhost:4200
```

## Production build

```bash
npm run build -- --configuration production
# Output in dist/frontend/browser
```

Backend must be running on port 8081. See the [root README](../README.md) for full setup instructions.
